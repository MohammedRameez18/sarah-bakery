# Sarah Bakery Landing Page Template

A modern, responsive one-page bakery website built using HTML, CSS, and JavaScript. It showcases a bakery’s products and services with a clean layout and smooth user experience.

⸻

# Features

* Responsive design
* One-page layout
* Modern UI
* Local fonts
* SVG icon sprite
* Original images included
* Smooth navigation
* Scroll Animation
* Theme Switch

⸻

# Website Sections

1. Header
2. Hero
3. About
4. Menu
5. Testimonials
6. Contact
7. Footer

⸻
